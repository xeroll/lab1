# Банк и финансовые операции

Лабораторная работа № 1 по дисциплине «Прикладное программирование»:
«ООП в Python. Обработка исключительных ситуаций. Форматы XML и JSON».
Вариант 21 — предметная область банка и финансовых операций.

## Возможности

- клиенты: добавление, просмотр, изменение телефона, удаление;
- счета: дебетовый и кредитный (с кредитным лимитом), открытие и закрытие;
- операции: пополнение, снятие, перевод между счетами, история операций;
- сохранение данных в JSON и XML и загрузка из них.

При ошибках (неверная сумма, нехватка денег, несуществующий счёт, повреждённый файл)
программа не завершается, а выводит сообщение и возвращается в меню.

## Запуск

Нужен Python 3.10 или новее, сторонние библиотеки не используются.
Запускать из папки проекта:

```bash
python3 main.py
```

При запуске загружаются данные из `data/bank.json`.

## Архитектура

| Слой | Файл | Классы | За что отвечает |
|---|---|---|---|
| main | `main.py` | `ConsoleApp` | Точка входа и меню |
| serviceLayer | `service_layer.py` | `BankService` | Бизнес-логика: проверки, открытие счетов, переводы |
| repositoryLayer | `repository_layer.py` | `BankRepository`, `FileStorage` | CRUD-операции и работа с файлами JSON / XML |
| dataLayer | `data_layer.py` | `Client`, `Account`, `DebitAccount`, `CreditAccount`, `Transaction` | Сущности |
| — | `exceptions.py` | `BankError`, `InsufficientFundsError` | Собственные исключения |

Каждый слой обращается только к слою ниже. Репозиторий и хранилище создаются в функции
`main()` и передаются в сервис через конструктор, поэтому способ хранения данных можно
поменять, не трогая бизнес-логику.
